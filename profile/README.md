# LeakTK - Leak Tool Kit

LeakTK is a place to open source and colaborate on some of our existing projects related to leak detection and prevention as well as greenfield a few new projects.

After enough of the individual components are brought over, a `leaktk` project will be added that starts tying them all together.

## Status

* Gitleaks 8 patterns maintained
* Scanner actively used today
* Working on open sourcing more internal components
* Need to flesh out the docs and guides more
